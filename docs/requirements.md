# 需求

实现状态保留已有需求核对结果；本次文档整理未重新审计全部功能。详细验收与已有验证依据见各组链接的专题，未注明适用代码版本的旧测试记录不代表当前版本已验证。

## 文档库与知识阅读

详细定义与验收边界见文档库的“对象与规则”“导航与阅读”“文件变化与冲突”“Git 与附件”，涉及窗口导航和操作对象的部分见桌面工作区。

[详细定义与验收](topics/document-library.md)。

### LOC-001

本地文件是唯一内容事实。用户、外部编辑器与 Agent 使用同一文档树；导航、关系、搜索和 Git 提示均可从文件重建。

- 实现状态：已实现。

### LOC-002

目录和 `index.md` 表达笔记层级，允许无正文的组织目录；`assets`、`canvas` 为保留目录，不允许笔记使用；扫描按定义排除隐藏路径、符号链接及无关目录，不预读所有正文。

- 实现状态：已实现。

### LOC-003

按 frontmatter 呈现标题与图标，普通笔记的概要、描述和自定义 YAML 数据保持原有展示，画布页也在白底风格头部展示同一信息，不提供 info 按钮；保留自定义字段的内容。 YAML 字段采用无边框、无背景的 DescriptionList，key 列按实际显示字体自动占宽并对齐，保持单行，属性行与概要所在区域采用紧凑间距，沿用现有样式。 支持对象和数组多层展开，保留数组顺序、空集合与 null，不以 JSON 字符串代替复杂属性。

- 实现状态：已实现。

### LOC-004

附件位于所属笔记的 `assets/`，专用图标位于 `assets/icon.png`；图标、画布和隐藏文件不计为附件；图片、图库和附件扩展按同一文件边界读取，无效资源显示可读错误。

- 实现状态：已实现。

### LOC-005

侧栏支持层级展开、选择、同级排序、附件数量和变化提示，Tree 留白使用内边距、滚动条贴边；排序独立持久化，不能改写内容目录。

- 实现状态：已实现。

### LOC-006

阅读常规 Markdown、表格、图片与代码，支持连续文本选择、全选和复制；代码正文完整显示且不进行语法高亮，不提供代码块专用复制按钮或展开收起。

- 实现状态：已实现。

### LOC-007

正式库内地址与正文链接能够定位笔记，越界目标被拒绝；用户可复制引用、在外部编辑器打开正文或在文件管理器显示目录。 编辑笔记和打开笔记所在目录收纳到笔记菜单，命令面板保留入口。

- 实现状态：已实现。

### LOC-008

归档隐藏目标笔记及其后代，设置中可发现显式归档项并逐项恢复；安全写入保留无关元数据、正文与文本格式。

- 实现状态：已实现。

### LOC-009

图标上传写入所属笔记的图标文件和 frontmatter，拒绝不安全目标；图像按定义保持比例，派生缓存不写入内容库。

- 实现状态：已实现。

### LOC-010

将正文、画布和附件的 Git 变化归并到笔记并向祖先汇总；Git 不可用或文档库不是仓库根时仍能阅读。

- 实现状态：已实现。

### LOC-011

文件变化触发后台投影与当前正文更新，保留有效阅读状态；删除或归档清除失效选择，迟到任务不得覆盖新选择，观察失败明确显示。

- 实现状态：部分实现。
- 缺口：已有资料未逐项明确剩余实现范围，需结合专题中的失败处理、持久化与待验收事项进一步核对。

### LOC-045

笔记通过 shortcuts 配置网站、GitHub 和目录入口，标题栏与命令面板可直接打开；子笔记按最近整组配置继承，支持整组覆盖与 null 阻断。目录复用笔记编辑器；MCP 区分本地配置、生效入口和继承来源。详细规则见文档库与 Agent 接入。

- 实现状态：已实现。

## 画布

详细运行、模版复用、资源与导出见画布专题；原生布局与命令见桌面工作区；Agent 编写规范见 locus-docs://canvas。

[详细定义与验收](topics/canvas.md)。

### LOC-012

有画布的笔记只在标题栏及头部元数据以下呈现唯一画布，不生成笔记装饰背景，标题栏固定背景与底部分隔线；无画布时显示正文，笔记及库切换释放旧网页。画布笔记仅保留 frontmatter、不写正文，既有混合笔记暂不整理，编写约束见 `locus-docs://canvas`。

- 实现状态：已实现。

### LOC-014

画布使用 canvas/index.html 与必需的 main.js，入口导出 async main(data)，不依赖 Node/npm/Vite。保存后通过刷新或重新打开生效；初始化失败可修复后重试。程序不自动转换或删除已有的 React 源文件。详细契约见画布专题。

- 实现状态：已实现。

### LOC-015

通过互斥的 canvas/index.json 以 template 与原样 JSON data 调用其他笔记的 HTML 模版，不支持模版链。资源归属明确，允许读取库内附件、画布文件、原始 YAML 和正文，拒绝越界及符号链接；详细契约见画布专题。

- 实现状态：已实现。

### LOC-016

基本页面与本地资源离线可用，主题变化不重载页面；脚本、网络、Worker、外部链接和资源加载受既定边界限制，画布不获得本机文件或 Shell 接口。 画布卡片与普通链接支持通过 locus:// 地址在当前工作区打开笔记，具体导航边界见画布专题。

- 实现状态：已实现。

### LOC-040

画布标题栏提供独立下载操作，后台导出已保存的 HTML、模版数据及引用资源快照；保留导出主题，不保存临时交互状态，不覆盖同名输出。默认系统下载目录，导出目录持久化于 TOML；完整边界见画布专题。

- 实现状态：已实现。

### LOC-017

画布焦点下刷新、关闭窗口、启动 Agent、命令面板和设置快捷键有效；macOS 使用独立 oneo-gpui-webview 包，保持高性能网页渲染，GPUI 组件和浮层在网页上方显示并接收输入，浮层期间网页继续运行。详细合成与验收边界见 画布专题。

- 实现状态：已实现。

### LOC-044

画布支持全选、复制、剪切和粘贴快捷键，按当前焦点和选区执行；适用编辑区域与平台菜单行为见桌面工作区。

- 实现状态：已实现。

## 桌面工作区与设置

详细定义与尺寸、快捷键和焦点验收见桌面工作区。共享配置的默认值、允许范围及错误契约见工程的“核心 shell 与 Rust 模块组织”“持久化”；跨界面质量约束见项目入口“视觉规范”。

[详细定义与验收](topics/workspace.md)。

### LOC-018

左栏导航与笔记页面使用共享 shell；共享 shell 彻底移除右栏，Theme Smith、Opus Index 与示例同步只使用左栏和主内容；左栏尺寸、折叠及按钮拖动隔离符合专题定义。

- 实现状态：已实现。

### LOC-041

共享 shell 在侧栏左下角用紧凑圆角描边容器显示比 text_xs 更小的 FPS 数字，悬停只改变背景，默认显示按帧耗时估算且受显示器刷新率限制的最大帧率；点击切换为当前帧率，再次点击切回，无其他性能功能；显示范围与统计规则见桌面工作区和工程。

- 实现状态：已实现。

### LOC-020

选择笔记更新祖先展开、侧栏位置和前进后退历史；新分支、失效路径、文档库切换和启动恢复按同一状态规则处理。

- 实现状态：已实现。

### LOC-021

命令面板统一检索命令与当前投影中的笔记，菜单、按钮和快捷键复用相同动作及启用条件；确认或取消后正确关闭并恢复焦点。

- 实现状态：已实现。

### LOC-022

笔记标题栏和侧栏右键菜单绑定实际操作对象，图标和归档操作不能误作用于另一篇当前笔记；正文不重复标题栏操作层级，标题栏不显示刷新画布按钮。

- 实现状态：已实现。

### LOC-023

设置在同一窗口替换工作区，返回恢复原状态与焦点；偏好、窗口状态和排序分别持久化，加载或保存失败可见，不将内存变化当作保存成功。

- 实现状态：部分实现。
- 缺口：已有资料未逐项明确剩余实现范围，需结合专题中的失败处理、持久化与待验收事项进一步核对。

### LOC-024

主题、语言和界面字号遵循共享默认值与范围；主题、原生窗口、应用文案、组件 locale 和菜单同步变化，显式选择被保留。

- 实现状态：已实现。

### LOC-025

界面和 Markdown 代码字体按各自职责生效；编辑器、文档库、导出目录、终端选择、Agent 选择与 MCP 偏好由单一设置实体持有，旧内嵌终端设置移除且其他有效偏好保留。

- 实现状态：已实现。

### LOC-026

恢复有效窗口位置、普通窗口尺寸、侧栏状态与当前选择，避免标题栏落在不可操作区域；关闭和重新激活符合平台及构建模式约定。

- 实现状态：已实现。

### LOC-042

未选择笔记时右侧标题栏仍可拖动窗口；Windows 使用符合平台的设置返回位置、标题栏窗口操作按钮及 由 GPUI API 设置的 Mica 窗口材质（应用不自行检测或降级），详细交互与边界见桌面工作区。

- 实现状态：已实现。

### LOC-027

中英文、明暗主题、窗口缩放和长内容保持可读；关键操作具有键盘路径、可见焦点和可访问名称，状态真实，动画尊重减少动态效果。

- 实现状态：已实现。

## Agent 接入

详细工具契约、默认端口、监听与错误边界见 Agent 接入。工具消费 LOC-001 至 LOC-004 的同一文件模型。

[详细定义与验收](topics/agent-access.md)。

### LOC-032

通过只读 MCP 工具分页列出直接子笔记、包含检索内容或解析已知路径；路径参数支持库内相对路径与 locus:// 地址，返回元数据和原始文件路径；路径、读取和未配置文档库错误明确可见。

- 实现状态：已实现。

### LOC-033

每次工具调用读取真实文件；标准接口客户端自行编辑，完整接口执行库内内容操作，两者共享唯一内容事实，不增加模型调用、Agent loop 或通用权限系统。

- 实现状态：已实现。

### LOC-034

MCP 默认关闭，支持本机与局域网监听；Host 校验受限，局域网启用前说明无认证服务所暴露的信息，绑定失败不得伪装运行。

- 实现状态：已实现。

### LOC-035

应用维护唯一服务生命周期，配置变化先停后启，退出回收服务；设置保留服务开关、局域网开关、端口、真实运行状态及启动错误；侧边栏左下角只读显示服务状态。连接展示与移除范围见 Agent 接入。

- 实现状态：已实现。

### LOC-037

同一服务通过完整 MCP 地址提供逻辑对象发现与笔记库读写；模型无需访问服务端磁盘，接口生成的结果与错误不返回具体文件路径。完整范围及对象规则见 Agent 接入。

- 实现状态：已实现。

### LOC-038

通过完整地址上传、下载并管理笔记、附件、图标与画布，支持子树导出和重建；传输、校验、限制与失败恢复见 Agent 接入。

- 实现状态：已实现。

### LOC-039

完整接口按版本检测冲突，明确重命名、移动、引用与删除范围，拒绝越界及旧会话误写；与标准接口共用既有局域网设置与服务生命周期，详细边界见 Agent 接入。

- 实现状态：已实现。

### LOC-043

附件与画布规范作为软件功能，以英文随应用维护并打包到资源目录；Agent 可通过标准与完整 MCP 入口直接发现并读取，不依赖笔记库中的使用说明。仅包含功能用法、接口与运行边界，不包含笔记库的视觉偏好或模版清单；资源地址与读取边界见 Agent 接入。

- 实现状态：已实现。
