# 专题

[需求](../requirements.md)汇总完整需求清单与模块划分；以下专题分别维护具体行为、接口、边界和验收条件：

- [文档库](document-library.md)：笔记与附件模型、Markdown 阅读、画布、文件变化和 Git 投影。
- [画布](canvas.md)：HTML 入口、JSON 模版、资源访问、手动刷新与导出。
- [桌面工作区](workspace.md)：窗口布局、笔记画布、导航、命令、设置、焦点与界面状态。
- [文档库终端](terminal.md)：外部终端和 Agent 选择、笔记库根目录启动与失败处理。
- [Agent 接入](agent-access.md)：标准 MCP 发现、完整笔记库操作、内容传输及服务生命周期。

构建发布设施见[工程](../engineering.md)及[应用打包](../engineering/application-packaging.md)。
