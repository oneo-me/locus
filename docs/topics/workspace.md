# 桌面工作区

验证记录只覆盖已注明的测试范围与反馈对象；未注明适用提交的既有记录，其代码版本未知，不代表当前版本重新通过验证。

当前需求清单见[需求](../requirements.md)。本篇维护详细定义与适用验收边界。

## 目标

桌面工作区把文档导航、当前笔记、终端和设置组合为连续的原生桌面体验。它拥有窗口内呈现、选择、焦点、面板与导航历史，不拥有文档内容事实、外部终端实现或 MCP 工具语义。

画布标题栏的下载操作与通用设置的导出目录共同提供文件导出；对象绑定、输出与恢复契约见[画布](canvas.md)的“画布导出”。

## 工作区结构

主界面与设置侧栏统一透出共享 Shell 的背景材质，设置根容器和侧栏不额外覆盖原生材质。macOS 两处侧栏透出共享 Shell 的系统 Sidebar 模糊材质；共享中性底色在明暗主题下均使用 alpha 0.85（85% 不透明、15% 透明）。工作区由侧栏区域绘制染色，设置由根容器绘制染色；普通主内容保持不透明，画布区域由不透明 WebKit 页面提供背景，其 GPUI 祖先保持透明。Windows 工作区背景保持透明，设置根容器与侧栏不绘制不透明背景，直接透出由 GPUI API 设置的原生 Mica 及其主题染色；主内容和设置内容区保持不透明语义表面。应用不自行检测支持情况或实现降级；其他平台继续使用不透明底色。

主窗口使用左侧文档导航和当前笔记页面。共享 Shell 只组合左栏与主内容，不提供右栏布局、状态、动作或配置接口。左栏可折叠和拖拽调宽，按下后移动与释放通过窗口级捕获监听处理，不依赖根元素 hover，跨入画布或其他遮挡区域仍持续调整，松开后停止并保存宽度；默认及最小宽度为 252 个逻辑像素，中部保留可用阅读宽度；Locus 初始及最小窗口宽度为 980，初始及最小高度为 820。左栏按钮、分隔线与折叠状态由同一壳层协调，工具按钮上的单击、拖拽和双击不触发窗口移动或缩放。

当前笔记存在 `canvas/index.html` 或 `canvas/index.json` 时，标题栏及头部元数据以下只呈现唯一所属画布，不渲染 Markdown 正文或笔记装饰背景；画布拥有滚动和溢出处理，无画布时正文占满页面。画布页在标题栏下方展示概要、描述及自定义 YAML 字段，复用普通笔记的字段内容和排版，背景为白底风格并跟随明暗主题。元数据按内容确定高度，过长时在头部独立滚动，画布占据剩余空间，两者不重叠；无元数据时不占用额外高度。画布模式的标题栏、概要和 YAML 区域使用全部可用宽度，不受普通笔记的最大阅读宽度限制；保留左右内容内边距，并避让窗口控制按钮。信息区使用紧凑的上下留白与字段行间距，普通笔记保持原有宽度和排版。画布标题栏始终采用普通笔记向下滚动后的背景与底部分隔线，浅色主题下为白底，深色主题跟随语义主题。不增加右栏标签、画布标签栏或可调分隔设置。画布左侧固定预留 1px，不随界面字号放大；标题栏右侧不再为右栏折叠按钮预留空间，只保留正常内容内边距。移除“自动打开画布”开关。文件观察发现当前笔记新增画布时创建区域，删除画布时释放区域并恢复正文全高；已有画布文件保存后不自动刷新；用户通过画布快捷键刷新或重新打开笔记后生效，刷新重建临时状态。

画布由当前笔记身份拥有。进入有画布的笔记时自动创建但不抢夺阅读焦点，离开笔记、清空选择或切换文档库时释放网页；重新进入重新读取文件并执行脚本，不持久化网页状态。标题栏不提供画布刷新按钮；画布焦点下使用刷新快捷键；WebView 创建失败后可离开并重新进入笔记重试。

画布焦点下 Command/Ctrl+W 保持关闭窗口语义，Command/Ctrl+E 打开命令面板，Command/Ctrl+, 打开设置，Command/Ctrl 与反引号启动外部 Agent。设置替换工作区时隐藏并保留网页，返回后恢复；命令面板及其过渡、dialog、sheet 和菜单在网页上方显示，网页继续运行，浮层区域接收 GPUI 输入。合成、焦点与验收边界集中见[画布](canvas.md)的“原生 WebView 合成”。外部终端行为统一见[文档库终端](terminal.md)。

画布支持 Command/Ctrl+A 全选、Command/Ctrl+C 复制、Command/Ctrl+X 剪切和 Command/Ctrl+V 粘贴。操作作用于当前聚焦的输入框、文本域、可编辑内容或页面选区；剪切和粘贴仅修改可编辑目标，普通页面文字保留只读语义。macOS“编辑”菜单提供同一组命令，由原生 WebView 按当前焦点、选区及可编辑状态处理，不增加脚本读取剪贴板的宿主接口。

Locus 当前不使用知识图谱，不提供图谱标签、命令、笔记参与开关或附件显示偏好，也不在启动及文件更新时构建图谱。

左侧栏默认及最小宽度为 252 个逻辑像素；标题栏右侧、正文与底部左侧可扩展。底部右侧的设置按钮与 Command+, 打开同一设置入口，底部按钮与侧边、底边的内边距均为 0.5 rem。设置在当前窗口内替换工作区，使用同宽的分类导航侧栏和内容页；返回条目位于侧栏顶部，仅在 macOS 下避让交通灯标题区，颜色与设置导航条目一致，内容区保留空白拖拽标题栏，分组使用 13/16 rem 圆角容器；返回后恢复原工作区与焦点，不创建独立窗口或重复业务状态。左侧文档导航使用 GPUI Kit 的 Tree 实现层级列表，保留既有行高、缩进、圆角和选中效果，横向留白使用列表内边距，滚动条贴齐侧栏滚动区域右边缘；键盘上下移动选择，左右键和 Enter 展开或收起当前分支。文档导航和设置导航的选中与鼠标悬停背景统一使用 5% 透明度的主题前景色，并以完整前景色显示选中文字与图标，不能依赖固定灰色层级表达状态。窗口位置、普通窗口大小、侧栏显隐与宽度、当前选择属于界面状态，与用户偏好分开持久化。共享壳仅在 Debug 构建中于侧栏左下角以紧凑的圆角描边容器显示比 text_xs 更小的帧率数字，悬停只改变背景，文字和描边保持不变，位于底部状态内容与设置按钮之前，标题栏不再显示帧率，默认显示按平均绘制耗时估算且受当前显示器刷新率限制的最大帧率；点击切换为当前帧率，再次点击切回。悬停提示和可访问名称说明当前模式及切换结果，支持键盘激活；点击不触发标题栏拖动，不提供其他性能功能，不显示右下角浮层；Release 不显示，不属于产品持久化状态。统计与刷新机制见[工程](../engineering.md)。

命令面板通过 macOS“显示”菜单或 Command+E 打开，再次按 Command+E 关闭；它在同一个可搜索列表中提供应用命令、当前笔记命令和带笔记图标的可见笔记导航。命令入口复用菜单、标题栏与快捷键使用的同一 Action 及启用条件；笔记搜索只消费当前文档库投影，不读取全部正文或建立第二份索引。面板显示在窗口上部偏下的位置，面板与遮罩在打开和关闭时同步连续过渡；确认命令或笔记后关闭面板，Escape 取消并恢复原有焦点。

## 导航与笔记状态

- 选择笔记时更新祖先展开链、侧栏滚动位置和窗口内前进后退历史，再从[文档库](document-library.md)加载正文。
- 普通选择清空已有前进分支；前进、后退和鼠标侧键走同一状态转换。切换文档库清空历史，失效路径从历史中移除。
- 启动时只恢复当前投影中仍存在的选择；当前笔记删除或归档后关闭页面，不把旧正文留作有效内容。
- 每篇笔记的操作菜单可从阅读页标题栏按钮或侧边栏笔记行的右键菜单打开；侧边栏不附加常驻菜单按钮。两处菜单直接绑定目标笔记，提供编辑笔记、打开笔记所在目录、图标上传和归档，不能依赖另一篇当前选择来执行；前两项不再单独占用标题栏按钮，命令面板保留对应操作。
- 正文刷新期间保留阅读位置和现有内容；切换笔记或正文实际变化时清理不再属于当前内容的选择与临时交互状态。
- 标题栏集中提供当前笔记相关操作，不在正文顶部重复建立页面标题层级。普通笔记的概要、描述及自定义 YAML 字段保持正文头部的原有展示方式，不提供 info 按钮。画布页采用固定白底风格的标题栏与底部分隔线，深色主题跟随语义主题，标题栏及头部元数据以下显示画布。标题栏不显示画布刷新按钮。画布标题栏不提供下载操作。
- Cmd/Ctrl+R 与 F5 刷新当前获得焦点的画布，否则重新读取当前笔记正文；离开笔记时关闭该笔记的画布，重新打开时重新加载文件。
- Markdown 正文使用 GPUI Kit TextView。围栏代码块完整显示代码正文，使用代码字体和主题前景色，不进行语法高亮，并参与整篇笔记的连续选择与复制；不提供代码块专用复制按钮或展开收起。

## 设置与偏好

设置实体是运行时偏好的唯一来源，覆盖：

- 文档库路径与外部编辑器。
- 已归档笔记的查看与恢复。
- 共享 Shell 提供主题、语言和界面字号：主题和语言默认跟随系统，保留亮色、暗色、简体中文与 English 的显式选择；默认值、字号范围、系统语言解析与生效时机见[工程](../engineering.md)。
- Locus 提供界面字体、代码字体及其字号。
- 外部终端和 Agent 选择，详细选项及启动规则见[文档库终端](terminal.md)。
- MCP 开关、监听范围、端口、真实连接状态，以及标准/完整接口对应的连接地址与客户端配置。

偏好保存失败必须保持可见，不能把内存变化伪装成已持久化。主题变化同步 GPUI 语义主题与原生窗口外观；语言变化同步应用文案、可访问名称、组件 locale 与原生菜单。

## 交互约束

- 未选择笔记或选中无正文的目录时，右侧标题栏的文字与全部空白区域均可拖动窗口。
- Windows 工作区与设置页标题栏右侧显示最小化、最大化或还原、关闭按钮；按钮与业务标题、工具栏并排布局，不遮挡内容。窗口按钮采用共享标题栏的紧凑正方形尺寸与主题圆角，在标题栏内垂直居中，上下及右侧留白一致，按钮之间使用小间距。关闭按钮悬停时显示红色背景与白色关闭图标，按下时保持白色图标并使用更深的红色背景，移出后恢复默认外观。Windows 笔记标题栏使用可用的全宽；窗口按钮使用系统命中区域，最大化状态显示还原图标，键盘激活遵循相同操作，关闭遵循既有构建模式约定。
- 设置返回按钮上方仅 macOS 保留交通灯标题区；Windows 返回按钮顶部使用与左右相同的 0.75rem 边距，右侧仍保留可拖动标题栏和窗口按钮。
- Windows 材质通过 GPUI 的 `set_background_appearance(MicaBackdrop)` 设置，不维护应用侧的 Windows 材质能力检测和 Blur 降级。锁定的 gpui-pre-windows 0.3.3 在系统版本低于 build 22621、版本读取失败或 DWM 设置失败时直接返回，没有执行自动降级；不支持时接受框架默认表现。系统透明效果与可访问性策略决定实际呈现。明暗主题同步原生材质，主内容与设置内容区保持不透明，工作区侧栏与设置侧栏透出原生材质。
- 标题栏可拖动区域与按钮命中边界必须分离；面板按钮不能触发窗口拖动。
- 侧栏折叠与窗口联动尊重系统减少动态效果，过渡期间不挤压当前内容或隐藏恢复入口。
- 所有按钮、菜单、标签和分隔拖拽提供明确角色、可访问名称、可见焦点和必要键盘路径。
- 空、加载、错误、禁用、选中和完成状态来自真实业务状态，不用说明布局或实现进度的文案填充界面。
- 界面缩放、本地化长文本、路径、代码和表格必须在支持窗口范围内保持可读，不造成页面级横向溢出。
- macOS Release 关闭主窗口时保留可重新激活的应用窗口；Debug 构建可以随主窗口关闭退出。窗口恢复不得把标题栏放到当前显示器可操作区域之外。

## 实现边界

- `source/crates/locus-workspace/src/workspace.rs` 编排业务状态和导航、正文实体，`source/crates/locus-workspace/src/workspace/` 子模块分别承载导航、笔记、窗口 chrome、栏目缓存、笔记画布和外部终端启动。
- `source/crates/locus-settings/src/` 拥有偏好实体、设置页面和产品 workflow；有跨 frame 状态的输入与选择在实体创建时建立并长期持有，具体控件行为由 `gpui_kit::component` 提供，产品设置内容通过共享设置壳呈现。
- `oneo-gpui` 拥有应用初始化、窗口创建与恢复、重新激活、工作区与设置模式、面板状态、菜单、快捷键、窗口联动和平台行为；Locus 不复制其状态机。用户偏好通过其 TOML 配置服务保存，路径与错误契约见[工程](../engineering.md)。
- `gpui_kit::component` 是主题、图标、滚动条和通用控件来源；业务组合不能建立平行组件体系。

工作区变更必须核对普通窗口、全屏与最大化、左侧栏显隐和拖拽、画布独占内容区、设置往返、焦点恢复、键盘路径、长文本、两种主题及中英文状态。视觉判断由用户实际运行确认。

待用户验证：打开带自定义 YAML 的普通或画布笔记，标题栏保留复制、适用的画布下载与笔记菜单，命令面板不提供自定义网站、GitHub 或项目目录入口；编辑笔记与打开笔记所在目录仍作用于所选笔记。

## 窗口材质与标题栏验证

侧栏材质统一（部分验证）：Locus 的 `Settings::render`、共享 `SettingsShell` 根容器与 macOS 侧栏均不绘制不透明覆盖，设置侧栏透出工作区根容器的共享底色与原生材质；设置内容区由 `SettingsShell` 保持不透明。已核对 `Workspace → Settings → SettingsShell` 完整背景链及设置导航滚动容器。`cargo test -p locus-settings --all-targets --locked --offline` 通过 2 项测试，覆盖字号标签和中英文资源解析，不作为背景视觉验收。`cargo clippy -p locus-settings -p locus-workspace --all-targets --all-features --locked --offline -- -D warnings`、`cargo fmt --all -- --check` 与差异检查通过。共享壳既有测试覆盖导航、返回和焦点恢复，不证明产品设置页的材质叠加效果；macOS 明暗主题下进入设置、切换分类与返回后的背景一致性及文字对比度待用户验证。本次未运行 Windows 编译或实机验收。

自动化验证（Mica 透明背景修复前的覆盖）：`cargo test -p oneo-gpui -p locus-workspace --lib --locked --offline` 通过 64 项测试，覆盖空笔记标题栏拖动区域的完整尺寸、窗口按钮占位与关闭动作、设置返回布局与焦点恢复，以及共享底色 alpha 0.85。共享示例 3 项测试、Theme Smith 工作台 20 项测试通过；两包全目标 Clippy、Locus 入口编译和格式检查通过。

窗口按钮与设置返回布局的自动化验证：`cargo test -p oneo-gpui --lib --locked --offline` 通过 28 项测试，包含窗口按钮尺寸、上下与右侧留白、鼠标及键盘关闭动作，以及平台对应的设置返回边距；共享壳全目标 Clippy 与格式检查通过。上述检查覆盖窗口按钮与设置返回布局，不作为对应 Mica 透明背景的自动化验证证据。

Windows 实机验证（用户确认）：提交 `c93c3ba` 的 Windows 版本验证通过，对应工作区与设置侧栏透出原生 Mica 的效果已通过用户验收。本机未完成 Windows 专属分支编译，工具链限制见工程；实机结果不记作 Agent 编译或自动化测试通过。
